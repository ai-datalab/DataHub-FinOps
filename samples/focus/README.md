# FOCUS cross-vendor sample

`focus_sample.csv` is the unmodified 1,000-row FOCUS 1.0 extract from the
[FinOps Foundation FOCUS Sample Data project](https://github.com/FinOps-Open-Cost-and-Usage-Spec/FOCUS-Sample-Data).
It is anonymised sample data, not this installation's spend.

- Source revision: `adbdd17a132984d6e8583c149c236d2199c3f5bc`.
- Source file: `FOCUS-1.0/focus_sample.csv`.
- SHA-256: `e91e5ac7edf01ed2c9d926f37ef7dc1ae2aae97956fea8da6c9ee488b1c2839e`.
- Providers present: AWS (942 rows), Microsoft (51), Oracle (7). No Google Cloud rows
  appear in this extract, although the wider upstream collection describes Google data.
- All 1,000 rows use USD. Billing periods start in September and October 2024.
- Values, dates, identifiers and row counts have not been shifted or rescaled.
  This small extract does not represent complete invoices or comparable vendor workloads.
